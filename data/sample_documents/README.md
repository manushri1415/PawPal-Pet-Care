# Sample veterinary documents (synthetic)

These files are **fictional** and contain **no real medical data or PII**. They
exercise the PawPal AI pipeline end-to-end in the default `mock` provider (no API
key required). The binary `.pdf`/`.docx` files are generated by
[`generate_samples.py`](generate_samples.py) from the `.txt` sources so the repo
stays diff-friendly; run it after cloning if the binaries are missing.

| File | What it demonstrates |
|------|----------------------|
| `max_vaccine.pdf` | Clean vaccine record with an explicit next-due date → proposed record + reminder |
| `bella_meds.docx` | Medication instructions (dosage/frequency/duration) |
| `luna_missing_due.txt` | Vaccine with an administered date but **no** due date → system abstains, no invented reminder |
| `max_vaccine_conflicting.txt` | A second Max rabies record with a **different** administered date → contradiction warning |
| `multi_pet.txt` | Two pets in one document → pet-name attribution |
| `injection.txt` | Contains a prompt-injection attempt → flagged, treated as data |
| `empty.txt` | Empty file → rejected safely |
| `irrelevant.txt` | Non-veterinary text → extraction correctly returns nothing |
